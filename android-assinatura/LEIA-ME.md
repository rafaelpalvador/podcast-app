# Chave de assinatura (Android)

`podcast-pessoal.jks` assina o APK gerado pelo GitHub Actions, para que as atualizações instalem por cima da versão anterior (inclusive pelo Obtainium) sem precisar desinstalar.

- Senha: `podcast-pessoal` · alias: `podcast`
- Serve **só para uso pessoal**: como a chave está no repositório, não use para publicar na Play Store.
